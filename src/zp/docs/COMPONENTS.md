# Components

Every component below has: a **spec** (behaviour, variants, states, mutations, don’ts — the rule), a **reference page** (every variant × state drawn, `reference/*.html`), and the CSS classes in `css/zp-components.css`.

Frame names in the reference pages follow `<component> / <variant> / <state>` — implement exactly those variants and states, nothing more.

## Markup reference

Canonical markup produced by the library (icons abbreviated; use Lucide, 1.5 px stroke, `currentColor`). Wrap the app (or a root element) in `class="zp"`; set the theme with `data-theme` on `<html>`.

### Button — primary

```html
<button type="button" class="btn primary"><svg …lucide icon…></svg><span>Move to Costing</span></button>
```

### Button — secondary / ghost / danger / link

```html
<button type="button" class="btn secondary"><span>Cancel</span></button>
<button type="button" class="btn ghost"><svg …lucide icon…></svg><span>View pipeline</span></button>
<button type="button" class="btn danger"><svg …lucide icon…></svg><span>Delete</span></button>
<button type="button" class="btn link"><span>Back to current</span></button>
```

### Button — sizes and states

```html
<button type="button" class="btn primary sm"><span>Save</span></button>
<button type="button" class="btn primary lg"><span>Save</span></button>
<button type="button" class="btn primary" aria-disabled="true"><span class="spin"></span><span>Save</span></button>
<button type="button" class="btn primary  is-disabled" aria-disabled="true"><span>Move to Costing</span></button>
```
